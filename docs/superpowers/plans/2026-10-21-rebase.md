# Rebase Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `kiln rebase OLD NEW IMAGE --tag NAME` swaps an image's base layers for a patched base without rebuilding, refusing with a reason when the swap is unsafe.

**Spec:** `docs/superpowers/specs/2026-09-30-kiln-design.md` rev 2.5, §5.1, §6.4 and §16.

**Architecture:**
- `kiln-erofs` gains:
  - `squash_upper`, a squash that keeps overlay markers;
  - `Merged`, a merged view over a layer stack with lookup, readdir and file data;
  - `Image::walk`.
- `kiln-image` gains:
  - the base record and labels in the config;
  - `ConvertOptions::base` and boundary matching;
  - `rebase` with its pure gates in `rebase/gates.rs`;
  - shadowed-path collection in `rebase/shadow.rs`.
- `kiln` gains `convert --base` and `rebase`.

## Tasks

- [ ] **1. Spec.** Write §16, and amend §5.1 and §6.4 (rev 2.5).
- [ ] **2. `kiln-erofs`.** Add `squash_upper`, `Merged` and `Image::walk`. Unit-test the upper-squash rules:
  - whiteout over a lower entry;
  - a directory over a non-directory becomes opaque;
  - opaque is kept through a later non-opaque directory;
  - hardlinks stay shared.
- [ ] **3. Config.** Add `labels` to `ContainerConfig` and `KilnConfig`, and `BaseRecord` to `KilnConfig`. A config without them serialises unchanged, so existing digests hold.
- [ ] **4. Convert refactor.** Split `convert_image` into `convert_layers(range, lowers prefix)` and `commit_manifest`. Existing tests must pass unchanged.
- [ ] **5. Boundary-aware convert.** Match the boundary, squash each side separately, and record the base. Tests:
  - an unsquashed base;
  - a squashed base, with and without the hint;
  - an image not on the base;
  - an image that is only the base;
  - `--max-layers` not above the base's count.
- [ ] **6. Gates.** One pure function per gate, plus env and label merging. Unit tests for each refusal and each pass.
- [ ] **7. Rebase.**
  - Load the three images.
  - Run the cheap gates.
  - Re-derive the app layers.
  - Run the shadow gate.
  - Squash, commit and tag.

  Integration tests in `kiln-image/tests/rebase.rs`, one refusal per gate.
- [ ] **8. CLI.** Add `convert --base` and `rebase`, with a `kiln/tests/cli.rs` end-to-end test:
  - convert a base, an app on it and a patched base;
  - rebase;
  - check the report;
  - a copied-up config file trips the shadow gate.
- [ ] **9. Boot.** In the Lima VM, `kiln run` the rebased image.
